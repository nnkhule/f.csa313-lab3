## Гурван чанарын сценарио

### 1. Performance — /cart/add хариу хугацаа

| Хэсэг | Тодорхойлолт |
|---|---|
| Тойм | Худалдан авагч сагсандаа бараа нэмэхэд систем хэвийн ачааллын үед хариуг хэдэн хугацаанд буцаах ёстойг тодорхойлно. |
| Системийн төлөв | Систем идэвхтэй, `/cart/add` endpoint саадгүй боловсруулагдана. |
| Орчны төлөв | Хэвийн ачаалал: 20 VU зэрэг идэвхтэй, 1 минутын турш. |
| Гадаад өдөөлт | Худалдан авагч "Сагсанд нэмэх" товч дарж POST хүсэлт илгээнэ. |
| Шаардлагатай хариу | Систем 200 OK хариу буцаана. |
| Хэмжүүр | p95 < 200 мс |

### 2. Reliability — /pay эвдрэлийн давтамж

| Хэсэг | Тодорхойлолт |
|---|---|
| Тойм | Төлбөрийн хүсэлт боловсруулах явцад системийн амжилтгүй болох магадлал ямар түвшинд байхыг тодорхойлно. |
| Системийн төлөв | Систем идэвхтэй, гуравдагч талын gateway-тай холбогдсон. |
| Орчны төлөв | 20 VU, 1 минутын турш, хэвийн ачаалал. |
| Гадаад өдөөлт | Хэрэглэгч төлбөр хийх хүсэлт илгээнэ. |
| Шаардлагатай хариу | Систем амжилттай/амжилтгүй хариуг үнэн зөв буцаана. |
| Хэмжүүр | error rate < 8% (POFOD ≈ 0.08) |

### 3. Availability — сервер гэнэт унаж, дахин асах

| Хэсэг | Тодорхойлолт |
|---|---|
| Тойм | Сервер гэнэт зогссоны дараа хэрэглэгчид үйлчилгээ авах боломж хэр хадгалагдахыг тодорхойлно. |
| Системийн төлөв | Систем ажиллаж байгаад гэнэт зогсоно (crash). |
| Орчны төлөв | 10 VU, 2 минутын турш, дунд нь 10 секундийн зогсолттой. |
| Гадаад өдөөлт | ЭВДРЭЛ: серверийн процесс гэнэт зогсоно. |
| Шаардлагатай хариу | Систем дахин асаж, хүсэлт үйлчлүүлэх боломжтой болно. |
| Хэмжүүр | availability ≥ 90%, сэргэх хугацаа ≤ 10 секунд |

## SLO хүснэгт

| Сценарио | SLI | Босго | Цонх / нөхцөл |
|---|---|---|---|
| Performance | /cart/add latency | p(95) < 200мс | 20 VU, 1 мин |
| Reliability | /pay error rate | rate < 0.08 (8%) | 20 VU, 1 мин |
| Availability | Бүх хүсэлтийн амжилтын хувь (checks) | rate > 0.90 (90%) | 2 мин, дунд нь 10с зогсолттой |

**Босго сонгосон үндэслэл:** Сервер `/pay` дээр ~5% алдаа зориуд суулгасан тул 8% гэдэг нь бодит суурь алдаанаас дээгүүр, боловч том биш бодитой хязгаар.

**Error budget (цагаар):** 2 минутын 10% = 12 секунд "эвдрэх эрх".
